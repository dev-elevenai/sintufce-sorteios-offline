# Segurança

O aplicativo é offline por projeto. Não adicione cliente HTTP, telemetria,
atualização automática ou servidor localhost sem revisão formal de arquitetura.

Nunca versionar chaves privadas, certificados de assinatura, bases reais,
pacotes com dados pessoais ou dumps de produção.

Falhas devem ser comunicadas diretamente à equipe responsável pelo SINTUFCE.
